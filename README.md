Focus-Flow

About the Project

Focus-Flow is an Android application designed to help university students manage their study sessions, organise tasks and improve their productivity.

Features

Study sessions with a timer and clock-in/clock-out functionality

Study History management

Task management

Star points and achievement tracking

Preferred study duration settings

Study reminders and notifications

Firebase Realtime Database integration for data persistence

Technologies Used

Java

XML

Android Studio

Firebase Realtime Database

Firebase Authentication

How to Run the Project

Download or clone this repository.

Open the project in Android Studio.

Allow Gradle to sync.

Configure Firebase using the appropriate google-services.json file for the registered Android application.

Run the application on an Android device or emulator.

Project Status

The application is under development and is undergoing final testing and preparation for academic submission.
